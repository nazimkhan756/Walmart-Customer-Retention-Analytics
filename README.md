# Walmart-Customer-Retention-Analytics
Customer Retention Analytics Dashboard using Power BI
📊 Project Overview

An interactive Power BI dashboard to analyze customer retention, churn behavior, loyalty programs, repeat purchases, and Customer Lifetime Value (CLV).

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

📈 Key Performance Indicators

- Customer Churn Rate
- Repeat Purchase Rate
- Customer Lifetime Value (CLV)
- Loyalty Tier Distribution
- Churn Reason Analysis

🖼️ Dashboard Preview

"Walmart Customer Retention Dashboard" (Walmart_Dashboard.png)

🎯 Business Objectives

- Identify customers at risk of churn.
- Analyze repeat purchasing behavior.
- Evaluate loyalty program performance.
- Understand promotion and sales channel effectiveness.
- Recommend strategies to improve customer retention.

💡 Business Recommendations

- Provide personalized rewards to high-value customers.
- Develop targeted campaigns for inactive customers.
- Evaluate promotions based on repeat purchases.
- Improve customer engagement across sales channels.
